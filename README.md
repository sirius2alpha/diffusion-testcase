# Diffusion Test Cases

Small, reusable test-case collection for joint audio-video diffusion models.

## Ref2VA

The current pilot set contains five MiniMax H3 Ref2VA cases covering image
identity, subject/scene separation, image-plus-video motion, image-plus-audio,
and multimodal reference composition. See the [Ref2VA case pack](diffusion_testcase/ref2va/README.md)
for prompts, assets, attribution, and license details.

## T2VA

The `diffusion_testcase/t2va/` directory is reserved for text-to-audio-video
cases; it currently contains only a placeholder README.
